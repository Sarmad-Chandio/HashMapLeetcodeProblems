# LeetCode HashMap Solutions

This project contains simple Java implementations of common coding interview problems using **HashMap** and **HashSet** techniques.

## Features

- **Compare Two Arrays**: Check if two arrays have any items in common.
- **Find Duplicates**: Find duplicate values in an integer array.
- **First Non-Repeating Character**: Find the first non-repeating character in a string.
- **Second Non-Repeating Character**: Find the second non-repeating character in a string.

---

## Methods Explained

### `itemsInCommon(int[] array1, int[] array2)`
- **Purpose**: Check if two arrays share any common elements.
- **Returns**: `true` if there is at least one common item, otherwise `false`.

### `findDuplicates(int[] myArray)`
- **Purpose**: Identify all duplicate values in the given array.
- **Returns**: A `List<Integer>` containing all duplicates.

### `firstNonRepeatingChar(String input)`
- **Purpose**: Find the first character in a string that does not repeat.
- **Returns**: The first non-repeating character, or `null` if none exist.

### `SecondNonRepeatingChar(String string)`
- **Purpose**: Find the second non-repeating character in a string.
- **Returns**: The second non-repeating character, or `null` if none exist.

